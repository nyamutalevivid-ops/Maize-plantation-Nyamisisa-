MAIZE PLANTATION MANAGER – Paid tracking + Saved labourers
==========================================================

NEW FEATURES
------------
1. AMOUNT PAID
   - For each worker enter how much you have actually paid
   - App shows: Due | Paid | Outstanding

2. SAVED LABOURERS
   - Worker names are saved automatically when you record labour
   - You can also add names manually under "Saved Labourers"
   - When adding workers, type a few letters and pick from the list
   - Tap a saved name to fill a worker row quickly

HOW TO USE
----------
Labour tab → + Add Workers
  - Fill name, quantity/hours, previous balance, and Amount Paid
  - Save All Workers
  - Names stay in the system for next time
